Improving Content Performance Using Machine Learning: A Study on the FlyRank ML Internship Dataset

Abstract

This project investigates how machine learning can improve website content recommendations using the FlyRank ML Internship dataset. A rule-based baseline and a Random Forest model were developed and evaluated using the same validation strategy. The machine learning model achieved better prediction performance than the baseline while identifying the most important content performance features. The analysis focuses on anonymized public-safe data and follows reproducible machine learning practices. The results suggest that machine learning can assist content teams in prioritizing website improvements more effectively.This research uses anonymized FlyRank content-performance data to study how simple machine learning methods can help prioritize content updates. The case study focuses on identifying pages with low click-through rates and stale content so that teams can make faster, data-driven refresh decisions. The results demonstrate that even straightforward predictive models can support content optimization while remaining safe for public sharing.

Introduction

Website content plays a major role in attracting users through search engines. However, deciding which pages should be refreshed or improved is often a manual process. This project explores whether machine learning can automatically prioritize content improvement opportunities using historical engagement and search performance metrics.FlyRank manages large collections of digital content. Reviewing every page manually is difficult, so this project explores whether machine learning can identify which content should be refreshed first. Using anonymized engagement metrics, the study evaluates baseline rules and machine learning models to improve content prioritization.

Data

  • Dataset: FlyRank ML Internship Dataset (Anonymized)
  • Rows: Approximately 30,000
  • Features: CTR, Engagement Rate, Word Count, Average Position, Content Age, Sessions and other public-safe metrics.
  • No private client information or URLs were used.

Methodology

  • Performed data cleaning and preprocessing.
  • Created a rule-based baseline model.
  • Trained a Random Forest classifier.
  • Used train/test split for evaluation.
  • Checked for feature leakage.
  • Compared both approaches using the same validation process.

Results

Method Observation
Rule-Based Baseline Provides simple prioritization using predefined rules.
Random Forest Produced stronger predictive performance than the baseline.
Important Features CTR, Engagement Rate, Average Position and Content Age.

The machine learning model demonstrated improved predictive capability while maintaining transparency through feature importance analysis.

Limitations

  • The dataset is anonymized.
  • Results are based on internship data only.
  • Different websites may require different models.
  • Future work could evaluate additional algorithms.

Ranked Recommendations

  1. Refresh stale pages with low CTR.
  2. Improve page titles and meta descriptions.
  3. Monitor high-performing content.
  4. Update aging articles regularly.
  5. Improve engagement on low-performing pages.
